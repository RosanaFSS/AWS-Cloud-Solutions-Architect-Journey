<h2  align="center" class="bold" style="font-weight: bold">Access Keys for IAM Users</h2>
<p align="center">Access keys are long-term credentials for an IAM user. You can use access keys to sign programmatic requests in the AWS CLI or AWS API (either directly or using the AWS SDK). <br>

Note: It is not recommended to use access keys directly in your code, as this is not a good security practice.<br>

Important: As a best practice, use temporary security credentials (like IAM roles) instead of creating long-term credentials such as access keys. Before creating access keys, evaluate alternatives to long-term access keys. Manage your access keys securely. Do not share your access keys with unauthorized third parties, even to help identify your account identifiers. Doing so could grant someone permanent access to your account. It is good security practice to rotate your access keys every 90 days.</p>
